\section{Background}
\label{sec:introduction-background}

% where to introduce U
In many partial differential equation (PDE) problems, the numerical solution is not required with uniform accuracy over the whole computational domain. What matters instead is an accurate value of a specific \emph{quantity of interest} (QoI), a functional
\begin{equation*}
  J : U \longrightarrow \mathbb{R}
  \label{eq:intro-qoi-map}
\end{equation*}
that encodes why the simulation is being run in the first place. Examples include the average temperature in a prescribed observation region, the effective multiplication factor of a fission reactor, and the drag on an airfoil. The relevant discretisation error is consequently
\begin{equation*}
  e_J = J(u)-J(u_h),
  \label{eq:intro-goal-error}
\end{equation*}
where \(u\in U\) denotes the exact solution and \(u_h\) its finite element approximation. Quantifying \(e_J\) is therefore necessary when the output, rather than the full state, informs the scientific or engineering conclusion.

% Classical adaptive finite element methods estimate the discretisation error in some global norm and refine wherever that error is not yet resolved. This is a reasonable strategy when the full solution is the object of interest, but if only a single scalar output is required, it can waste substantial computational effort correcting errors that barely affect that output.

Conventional adaptive finite element methods (AFEM) aim to control a prescribed norm of the state error,
\[
e_u:=u-u_h,
\]
by means of local a posteriori error indicators within a \textsc{Solve--Estimate--Mark--Refine} loop \cite{ENDTMAYER202419}. Common indicator constructions include residual, recovery-based, and equilibrated-residual estimators \cite{Ainsworth_Oden_1997}. Their purpose is to estimate and reduce a global norm of \(e_u\). Goal-oriented error estimation instead targets \(e_J\) itself and localises it to obtain refinement indicators for the chosen output \cite{Becker_Rannacher_2001,Bangerth_Rannacher_2003}.

The dual weighted residual (DWR) method provides a systematic framework for this purpose \cite{Becker_Rannacher_1996,Becker_Rannacher_2001}. It weights the residual of the discrete primal solution by a solution of the dual problem. The residual quantifies the defect of the discrete solution in the continuous variational problem, whereas the dual weight represents the sensitivity of the QoI to that defect.
For linear problems, the QoI error can be represented exactly as the primal residual evaluated at the difference between the exact and discrete adjoint solutions. In practice, this adjoint error is approximated using an enriched adjoint solution, which yields a computable estimator of the QoI error.
% should nonlinear case be mentioned here

For time-dependent problems, the global QoI-error estimate must be localised over spatial elements and time intervals to furnish indicators for mesh and time-step adaptation \cite{Becker_Rannacher_2001,Schmich_Vexler_2008}. 
Several localisation strategies for DWR estimators have been proposed, including classical elementwise integration-by-parts localisation, variational filtering over element patches, and variational partition-of-unity localisation \cite{ThieleWick2024,RichterWick2015}. The first produces strong cell, facet, boundary, and, for discontinuous time discretisations, temporal-jump residuals, whereas the latter two retain a variational representation of the residual and avoids the explicit construction of strong residuals.

This dissertation considers strong-residual localisation for a class of linear time-dependent problems. The objective is to automate the conversion of a weak residual into cell, facet, boundary, and temporal-interface contributions from a symbolic Unified Form Language (UFL) representation, thereby avoiding problem-specific derivations.

\texttt{Firedrake} expresses finite element variational problems using UFL \cite{Firedrake}. Starting from a semidiscrete UFL formulation, \texttt{Irksome} constructs the coupled stage equations associated with a chosen Runge--Kutta scheme \cite{Farrell_Kirby_Marchena_2021}. Recent work extends this automation to discontinuous Galerkin time discretisations \cite{andrews2026automatedgalerkintimestepping}.
\texttt{firedrake.adjoint} provides the corresponding discrete adjoint calculations using the methodology first published in \cite{Farrell_Ham_Funke_Rognes_2013}.
These symbolic primal and dual descriptions provide the basis for automatically constructing local strong-residual indicators.
